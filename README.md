# Telegram бот для создания тепловых карт

Бот для создания тепловых карт из Excel-файлов с сохранением статистики пользователей.

## Функциональность

✅ Загрузка Excel-файлов (.xlsx)  
✅ Настройка параметров тепловой карты  
✅ Сохранение статистики пользователей  
✅ Административная панель  
✅ Логирование всех действий  

## Команды бота

- `/start` - Начать работу с ботом
- `/help` - Получить справку
- `/stats` - Ваша статистика
- `/admin_stats` - Статистика бота (только для админов)
